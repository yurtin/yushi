## 一、数据

```js
S.zones = [ { k:'z_long', name:'长期', color:'…' }, { k:'z_short', … }, { k:'z_repeat', … } ]
S.zoneRules = ''                       // 「对 AI 的规范设置」的自然语言规则，默认空
S.zoneHints = { '课': { k:'z_xxx', n:2 }, … }   // 行为学习：词 → 分区 + 命中次数
// 条目上：it.zone = 'z_long' | 'z_xxx' | ''      （'' = 未分组）
```

### ⚠️ 标识与名字必须解耦

`k` 是主键，`name` 只是显示。**改名时绝不许动条目的 `it.zone`。**
这是本卡最容易埋的坑：拿名字当主键的话，用户改名之后**他所有条目会一起掉进「未分组」**。

### 「未分组」是内置兜底

- **不在 `S.zones` 里**，用 `it.zone === ''` 表示
- **不可删、不可改名**
- **空时不渲染**，且**固定排在最后**

## 二、迁移（老数据一个字不丢）

| 老 `zone` | 新归属 |
|---|---|
| `long` | `z_long`（默认分区「长期」） |
| `short` | `z_short` |
| `repeat` | `z_repeat` |
| `idea` | **不参与** —— 「想法」是独立机制，`zone==='idea'` 原样保留不碰 |
| 空 / 认不出 | `''`（未分组） |

- **只在 `load()` 做一次**，且**必须幂等**（迁移过的数据再跑一次结果相同）
- `sanitizeItems` 那一层跟着改：**认不出的 `zone` 一律落 `''`**（不许原样留着让它哪一栏都进不去）

**红线：迁移后不许出现"哪一栏都不收"的条目**（0B 那轮排查过同型 bug）。

## 三、清单页的 UI

### 3.1 分区渲染
- 顺序 = `S.zones` 的顺序；「未分组」固定最后、**空时不渲染**
- 每个分区标题右侧多一个 **「⋯」**

### 3.2 「⋯」里有什么

| 项 | 行为 |
|---|---|
| **改名** | 只改 `name`（就地输入或复用现有弹层，自己定） |
| **上移 / 下移** | 交换位置；首/末对应项禁用 |
| **删除** | **二次确认**，文案写清 `「学习」里的 N 条会移到「未分组」` |

### 3.3 新建分区
- 分区列表末尾一个 **「+ 新建分区」**（压在分区脚下，和 `.done-entry` 同区）
- **只要名字**（颜色默认循环取色，别让用户选）

### 3.4 删除分区（**红线最多的一条**）
**删分区 = 只把归属改成 `''`，一条条目都不许删。**
同时**清掉 `zoneHints` 里指向它的记录**（否则以后会预测到一个不存在的分区）。

## 四、AI 落点：**三级层次**（用户定）

```
① 用户写了 S.zoneRules（规范设置）
      → 出网问模型：把「规则 + 现有分区名 + 原话」给它，让它选一个
② 没写规则，但本地 S.zoneHints 命中
      → 本地直接定，零请求
③ 都没命中
      → 出网问模型：把「现有分区名 + 原话」给它
```

**失败/超时**一律**留空 → 未分组**（不许瞎猜）。

### 4.1 行为学习的具体设计（**照这个做，回报里说明最终形态**）

**教学信号有两个**：
- **用户把一条待办挪到分区 X**（清单页上改归属）
- **用户改了 AI 猜的分区**（`→ 学习` 那行小字旁边点一下换）

**怎么记**：
- 取这条待办**标题**的 **2-gram**（与 `aiScoreCandidate` 的"二元组字面重合"同一把刀，**别再引入分词依赖**）
- 每个 gram 在 `S.zoneHints` 里 `+1`，记到该分区：`{ gram: { k, n } }`

**怎么预测**：
- 新待办标题的 2-gram 去查 `S.zoneHints`，按分区累计得分
- **最高分 ≥ `ZONE_HINT_MIN`（定 2）且明显领先**（没有并列）→ 定它
- 否则 → 往下一层

**为什么要阈值 2**：一次教学可能是误操作；**两次才算数**。

**`zoneHints` 要有上限**（参照 `hotwordSeen` 那套的规模纪律），满了淘汰 `n` 最小的。数量与淘汰策略自己定，**回报里说明**。

### 4.2 用户要能看见它学了什么

**「规范设置」那块里列出来**（"已学会：课 → 学习，2 次"），**并且能一键清空**。

**理由**：不列出来就是黑箱 —— 用户会觉得"它怎么老往那分"，却找不到原因也没法纠正。

### 4.3 落点提示

录入后**一行小字**显示 AI/行为学的判断：`→ 学习`。**不同意点一下换** —— 那**又是一个教学信号**。
