# 鱼事

一个**单文件**的个人待办应用。整个应用就是 `鱼事.html` 一个文件（约 19,700 行 / 1.29 MB，HTML + CSS + JS 全在里面），
没有任何构建步骤、没有依赖、没有后端，双击就能在浏览器里跑。

同时打包成两个平台：

- **安卓** —— **一个 APK**（最新版见 [Releases](https://github.com/yurtin/yushi/releases)）：
  `鱼事-ai-vX.Y.Z.apk` —— 权限共 **7 条**（2026-10-13 按 `_android/app/AndroidManifest.xml` 逐条核对）：
  `RECORD_AUDIO`（危险权限，长按说话那一刻才申请）· `VIBRATE` · `POST_NOTIFICATIONS`（到点提醒）·
  `RECEIVE_BOOT_COMPLETED`（重启后把提醒排期接上）· `SCHEDULE_EXACT_ALARM`（准点提醒，系统不给会自动降级成非精确）·
  `USE_FULL_SCREEN_INTENT`（锁屏全屏响铃，设置里默认关）· `INTERNET`（只给 AI 那一栏用）。
  **没有**存储 / 定位 / 通讯录 / 相机 / 剪贴板权限；**AI 默认关闭**，要在设置里自己打开；
  关着的时候一个字都不出手机。
  > ★ 2026-10-04 用户定：**不再出双包**（原 `鱼事-pure-*` 那个不含 `INTERNET` 的纯净包停用）——
  > 理由原话："直接就是 AI 联网这个就行了，因为我觉得 AI 是一个必不可少的功能"。
  > 所以 `python _android\build.py` 仍可出纯净版，但**发版只走 `--ai`**；
  > 核验用 `python _android\_tools\verify_apk.py --ai`（不认 `--ai` 的老口径会按纯净版的权限集合断言，必红）。
- **iOS** —— 一个 PWA（渐进式 Web 应用），Safari 打开后「添加到主屏幕」即成为全屏独立 App

## 功能

四个页签 + 一个录入页，底栏图标切换（中间那颗圆钮是录入键：单击打字、长按说话）。
「时间轴」不是独立的页，是**清单页的一种展示模式**（`S.listMode`，右上角切换）：

| 屏幕 | 内容 |
|---|---|
| **清单** | 今天的待办，含复合目标（可嵌套子任务）、循环任务、优先级、标签、筛选、搜索；右上角可切「分区 / 时间轴」两种展示模式（时间轴按日期铺开，看逾期与堆积） |
| **想法** | 还没定型的念头。单列卡片流、从它**生长出来的**想法缩进在下面（带树形连接线）；每条有时间轴（续写）、可生长/合并/立项；用过了**变暗**沉底，不打勾。长按卡片出动作菜单。右上角「☰ 多选」可批量合并 / 立项 / 编辑 / 续写 / 生长 / 收起来 / 删除 |
| **统计** | 完成情况与子页下钻（今日/历史完成、连续打勾的热力图、已逾期、作业未交）；可切卡片 / 平铺布局 |
| **设置** | 四栏可折叠（**默认全收起**）：**功能**（提醒总开关、语音输入、锁屏全屏响铃）· **AI**（AI 连接、没写时间的条目默认去哪、常用词、发多少内容、对 AI 的规范设置）· **外观与体感**（主题、页面说明文字、流畅模式、想法卡片时间显示、震动档位）· **数据**（备份导出/导入、示例数据、AI 写过的话、版本号 → 更新日志） |

想法页的几个取舍（都不是拍脑袋定的，依据在 `设计稿-想法系统v5.md`）：

- **不打勾，只变暗** —— 想法没有"做完"这回事。用过了收起来，续写一句就亮回来。
- **长出来的想法靠缩进 + 连接线表达，不靠连线** —— 从一条想法分出去的，缩进在它下面。
  措辞上刻意不叫"子想法"：有时它是归属（本来就属于这条），有时是在它身上发展出来的新东西，
  用"父/子"会把关系说死。动作名也从「分叉」改成 **「生长」**。
- **右上角是「多选」不是「合并」** —— 合并只是众多同级动作里的一个，不该单独占着一个位置。
  进多选后可以选若干条，然后批量：合并 / 立项 / 编辑 / 续写 / 生长 / 收起来 / 删除。
  其中立项、编辑、续写、生长是**逐条**的（一次只开一个弹层，确定或取消都算过一条，
  自动跳下一条）；合并、收起来、删除是**一次性**的，配一个撤销。
- **顶部有「回顾」抽屉** —— 自动挑三条你最近没碰过的送到眼前；你用想法用得勤它就自己收着。
  理由是：调研里那位实践 GTD 五年的用户原话是"收集做得很好，但整理阶段做不好，最终 Inbox 越来越多"。
  **收集越顺，积压越重**，所以需要一件不要求你主动想起来的事。
- **「考虑区」已并入想法** —— 行尾带 `?` 的条目直接长成一条想法。原来的考虑区只有一行，
  记不下"我查了下、想了想"的过程，那恰恰是考虑一件事最需要的部分。
- **没写时间的条目默认去哪，可以在设置里改** —— 默认是**「自动」**（由 AI 判断落点；AI 关着时按日期推：
  14 天内有日期 → 短期，其余 → 长期）。也可以固定成某个分区 / 「想法」/ 「不进任何分区」。

设计上的一些取舍：

- **数据只存在本机** —— 全部在浏览器 `localStorage` 里，不上传任何服务器。联网版多出的
  `INTERNET` 只给 AI 那一栏用，**AI 关着时页面一个外部请求都不发**。
- **备份靠文件** —— 一键导出 JSON，换设备/换浏览器时导入即可。
- **动效克制** —— 折叠展开、页签滑动指示块、滚动揭示都做了，但遵循系统「减弱动态效果」设置。
- **键盘可达** —— 弹层有焦点陷阱与 `inert` 背景、页签有 `aria-current`、开关用 `role="switch"`。
- **软件渲染自动降级** —— 检测到走软件渲染（无 GPU 加速）时自动关掉昂贵的毛玻璃。

## 直接用

**安卓**：到 [Releases](https://github.com/yurtin/yushi/releases/latest) 下载最新的
`yushi-v*.apk` 安装（Releases 上是 ASCII 名，本机构建产物叫 `鱼事-ai-v*.apk`，同一个文件）。
装之前不用做任何事；第一次长按圆钮说话时会申请一次麦克风权限，不给也能用键盘输入。

**iOS**：用 **Safari** 打开 <https://daibanji.app.workbuddy.host/> →
分享 → 添加到主屏幕。

> 微信内置浏览器没有「添加到主屏幕」这个菜单项，需要先点右上角「…」→「在 Safari 中打开」。

**桌面**：直接双击 `鱼事.html`。

## 自己构建

### 安卓

需要 JDK 17（**不能用 21**，见下）、Android SDK 的 `build-tools;34.0.0` 与 `platforms;android-34`。

```bash
python _android/build.py
```

脚本默认读 `D:\Android\Sdk`，JDK 默认 `D:\java\java17`（可用环境变量 `DAIBANJI_JDK` 覆盖）。
构建在纯 ASCII 的 `D:\Android\build` 里进行，最后把 APK 拷回项目根目录。

**签名口令不进版本库。** 先准备好密钥与口令，二选一：

```bash
# 方式一：环境变量
set YUSHI_KS_PASS=<你的口令>

# 方式二：口令文件（已 gitignore）
copy _android\keystore\keystore.properties.example _android\keystore\keystore.properties
# 然后编辑 storePassword= 那一行
```

第一次运行时若 `_android/keystore/daibanji.jks` 不存在，脚本会自动用这个口令生成一个
27 年有效期的自建密钥。**这个文件和口令要自己留好** —— 换了它，已安装的旧版本就无法覆盖升级。

> ⚠️ **为什么口令不能写进代码**：安卓只认签名不认人。谁同时拿到 `.jks` 和口令，
> 谁就能签出包名与签名都一致的包，以「官方更新」的名义让已安装用户静默覆盖升级。
> 所以这两样都在 `.gitignore` 里。

### iOS / PWA

```bash
python _ios/build_pwa.py
```

生成 `_ios/dist/`，把整个目录部署成一个静态站点即可。版本号自动从
`_android/app/AndroidManifest.xml` 读取，两个平台共用一个来源。

## 一些实现上的坑（都写在代码注释里了）

- **`file://` 不能用来装 localStorage 数据**。安卓壳通过 `shouldInterceptRequest`
  把 `https://appassets.androidplatform.net/` 映射到 APK 内的 assets，
  请求在进网络栈之前就被拦掉，所以既不建 socket、也不需要 `INTERNET` 权限，
  同时 `localStorage` 拿到的是一个稳定正规的 https origin。
  （★ 5.0 起：页面本身仍然这么跑；联网版多出来的 `INTERNET` 只给 AI 那一栏用 ——
  它在设置里**默认关闭**，关着时页面一个外部请求都不发。）
- **JDK 21 编出来的 class 会让 d8 崩**。JDK 21 会给内部类构造器的 synthetic 参数写
  `MethodParameters` 且 `name_index = 0`，d8 解析无名参数时内部 NPE，报错位置和真凶无关。
  `-g:none` 关不掉，换 `--release` 也没用，只能换 JDK。
- **揭示动画不能用 `transition`**。组件的 `transition: transform` 简写会整体覆盖掉
  父级的 `opacity`/`filter` 过渡，导致同一页面两种节奏。改用 `@keyframes` +
  `animation-fill-mode: backwards`（不能用 `both`，会把终态 transform 永久钉住）。
